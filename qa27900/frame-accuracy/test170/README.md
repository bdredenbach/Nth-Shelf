# Source-layout detector controls

Run `node qa27900/frame-accuracy/test170/source-layout-contract.cjs` with the
runtime-provided `CODEX_PRIMARY_RUNTIME_NODE_MODULES` pointing at native canvas.
The 24 controls cover generated sizes/aspect ratios, measured cells and hosts,
whole/shared speech ownership, image/proof replay and rejection, reloads, and
the installed detector wrapper. They contain no comic-specific coordinates.

Run the current shell test and the existing test169 guard/test168 preparation
controls. The navigation test defaults to the frozen published `b9ebeeb`
Reader; it verifies that exact source hash and the independently reversed
historical source before running 55 baseline and 55 current cases. A local
restored baseline can be selected with `NTH_READER_BASE_REF` only when its
Reader matches the fixed expected SHA.

Comic qualification uses immutable independent source annotations and
`Reader.handleSingleTap`, real panel-map mathematics and native PNGs. Compare
all prior usable frames, not just failures. Preserve exact source and module
hashes, all original taps, complete page receipts and visual grades. Groups
are not usable singles. Private artwork/maps belong outside public Git/CI.

The rebuilt audit reports 67 usable story singles (from 32), 19 groups and
9 partial/wrong crops. It recovers 10 original failures and separates 25
groups, retaining every old usable story single and 88 approved Apocalypse
selections. The detector uses frozen verified upstream maps for this isolated
comparison, fresh source analysis, and current Reader routing. Its wrapper
has generated integration controls. This is not a full upstream corpus rerun
or browser/phone/worker-lifecycle and performance validation.

Established full source layouts delegate unchanged. The final sustained-rim
predicate was tightened after the native Apocalypse comparison; exact final
gate replay proves that predicate is dormant on all 22 approved story layouts.
The Reader was unchanged by that adjustment. Do not claim universal accuracy.

Source proposals are conservative. Next work must address partial/overlapping
rims, colored paper, foreground extensions and shared sound effects with
held-out annotation before tuning. Do not repair audit cases by manually
adjusting their rendered crops.
