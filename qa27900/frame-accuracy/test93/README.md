# Test93 contracts

Atomic source-enclosed speech ownership across an existing scene boundary. No source comic artwork is stored here. `geometry.json.gz.b64` contains captured descriptors and normalized/pixel contours only.

`run-retained.sh` runs 88 retained/new suites. `speech-ownership-contract.cjs` checks positive/negative source cases, malformed proofs, indivisible lettering, source-union preservation and unchanged non-speech artwork. `reader-speech-contract.cjs` checks 2,273 newly assigned speech taps, overlays, immutable cached proofs and corruption rejection. `service-worker.test.cjs` verifies the Test93 cache/install identity and required assets.

See `crop-review.json`, `corpus-summary.json` and the root handoff/validation. Android CI and phone acceptance are separate, pending checks.
