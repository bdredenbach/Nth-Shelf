# Detached source caption

`detached-caption-contract.cjs` checks a complete independently enclosed, lettered chromatic caption and rejects absent source ink, open enclosure, transparency, ambiguous bounds, unproven owners, foreign ink and duplicate ownership. The existing caption-repair behavior remains the default; the separate detached route has a strict unique-bounds and no-foreign-pixels gate.

Private source replay checks all24 issue1 source hashes,56 native Reader canvases and the real dark/final-overlay path. Only Reader14 S5 changes; the55 other PNGs and all prior metadata are equivalent. All3219 source-caption pixels select S5. The shared-composition pair receives a private continuity judgment; this source module does not decide which dialogue constitutes continuity.

`run-retained.sh` runs the prior155 suites with the current cache/package check plus the new caption contract. No APK is built. Browser/phone passes must not be inferred from native canvas replay.
