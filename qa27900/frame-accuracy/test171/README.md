# Source paper ownership

An independently measured closed source frame may replace an equivalent older
contour only when it retains at least 99.5% of that contour, expands ownership
by no more than 10%, and restores ink in at least two whole paper bodies.
Its four measured bounds must match the older frame within 3 analysis pixels
or 2.5% of the frame span. The old contour is comparison evidence; new geometry
comes exclusively from the source analyzer. One clipped body, overlapping
protected owners, smaller possible legacy insets, non-equivalent bounds,
excessive ownership expansion and malformed contours keep the prior owner.
