# Source overlap ownership

The source stage can close a rear rectangular inset when all four rail positions are measured and missing portions of its rim are covered by already closed foreground peers. Short contrast rails stop at sustained loss of contrast rather than inheriting a long artwork-darkness track. At least 36 pixels and 18% of each side must remain exposed and pass the existing strong-border requirement. Blank/paper-dominated interiors, grid envelopes and equivalent duplicate rectangles are excluded.

The resulting inset bank can qualify a surrounding host only under the existing width, dense-bank, image-variance and unresolved-inset checks. New masks are used to explain their own rims. Prior bounds serve only as a veto: a legacy inset already excluded from the source host mask cannot be swallowed by that host. Its coordinates never create geometry.

A white-outlined saturated source component substantially crossing a bank mask vetoes the new host. This deliberately defers shared lettering and foreground ownership instead of clipping a token at an inset hole. It is a safeguard, not a complete word/silhouette detector.

Work is bounded by 96 horizontal/vertical tracks, four million rail-pair visits, 300,000 eligible trials, and eight peer-closure passes. Exceeding a bound defers to upstream.
